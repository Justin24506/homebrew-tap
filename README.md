# Justin24506 Tap

## How do I install these formulae?

`brew install justin24506/tap/<formula>`

Or `brew tap justin24506/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "justin24506/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
